Where the AI is used

The model proposes; the parity test above decides. The model never judges whether a job will trip cooling, and it is never the only evidence for a "verified" claim.
  • Rewrite proposal. Reads the old code and writes a modern version. Screened for unsafe code, compared with the original on generated scenarios, then checked again on held-out ones. A failure goes back to the model with the first difference, up to 4 tries.
  • Glossary draft. Suggests plain names for cryptic tags. A person approves them.
  • Operator Q&A. Answers questions from the extracted rules, findings and tickets only.
